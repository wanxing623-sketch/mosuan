# 速算模考台 · 资料分析专项

单文件离线版

## 在线访问

启用 GitHub Pages 后访问：

`https://<你的用户名>.github.io/<仓库名>/`

## 本地打开

将 `index.html` 下载到本机后，用支持本地 HTML 的浏览器打开即可使用，无需联网、无需后端。页面不加载外部统计脚本，TXT 导入通过浏览器本地文件 API 完成，不上传题库。

注意：
- 首次访问 GitHub Pages 在线地址仍需联网；在线地址并不保证断网后能重新打开。
- 手机选择文件时，请选择“我的 iPhone / 本机 / Downloads”中已下载的文件。iCloud、网盘等文件提供程序可能需要联网下载文件，这不受网页控制。
- 若系统文件选择器无法使用，也可将 TXT 内容复制到“粘贴文本”区域导入。

## 文件说明

- `index.html` — 速算模考完整应用
- `.nojekyll` — 告诉 GitHub Pages 不要用 Jekyll 处理，保证原样发布
